# BitcodeX Examples

Starter examples for building dApps with BitcodeX. You can run each example locally
by following the instructions in the README.

## Requirements

- Node.js 22+
- Yarn (workspaces)

## Examples

- **[Cosmos Next.js Example](cosmos_nextjs)** — BitcodeX Cosmos SDK on Next.js
- **[CosmosKit Next.js Example](cosmoskit_nextjs)** — Next.js + CosmosKit with
  BitcodeX
- **[InterchainKit Next.js Example](interchainkit_nextjs)** — Next.js +
  InterchainKit with BitcodeX
- **[EVM Next.js Example](evm_nextjs)** — BitcodeX Ethereum SDK on Next.js
- **[EVM Wagmi Next.js Example](evm_wagmi_nextjs)** — Next.js + wagmi +
  RainbowKit with BitcodeX
- **[Multi-Ecosystem React Example](multi_ecosystem_react)** — React + Vite with
  BitcodeX for both Cosmos and EVM
