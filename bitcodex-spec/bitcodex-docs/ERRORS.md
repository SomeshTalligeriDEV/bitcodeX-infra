## Signing popup (`open_modal_ack` error, `@bitcodex/sdk-bittensor` rejects with it)

| `error.type` | Meaning |
|---|---|
| `unknown_error` | Unexpected failure while signing; `error` has details. |
| `network_refused` | The request's network is not allowed (mainnet, unknown chain, or not this app's network). |
| `signer_mismatch` | The payload is for a different account than the signed-in wallet. |
| `origin_not_allowed` | The requesting site is not in the app's allowed origins (developer dashboard). |

The user closing the popup rejects with `Error("Cancelled")` (`USER_CANCELLED`).

Chain errors are decoded by name (`section.Error`), e.g. `subtensorModule.SlippageTooHigh`, `swap.PriceLimitExceeded`, `proxy.NotProxy`, `system.CallFiltered`; a proxy call whose inner call fails rejects even though the outer extrinsic succeeded.
